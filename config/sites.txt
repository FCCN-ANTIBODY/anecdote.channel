# sites.txt — the directory anecdote.channel publishes.
#
# HOSTNAMES, not repos. A site is a name that answers; how it is hosted is nobody's business
# here. Reading a repo would assume GitHub forever and need a credential per org — a probe
# assumes nothing and needs none. Registration is a PR from whoever runs the site; verification
# is an ordinary HTTPS request anyone could make.
#
# Format: one hostname per line, plus optional space-separated flags, plus an optional `= label`.
#   system     — verify it (TLS, liveness) but NEVER publish it. Infrastructure other software
#                talks to, not a place to send a person.
#   draft      — hold it back from the directory entirely.
#   repo:<o/n> — resolve where this points FROM THE REPOSITORY (its Pages cname if it serves from
#                Pages, else its `homepage` field). Preferred over a typed URL: the owner controls
#                it, it survives them changing hosts, and a public repo needs no credential.
#   was:<host>  — a name this entry used to answer at. Repeatable. From outside, a rename and a
#                 deletion look identical — the host stops answering — so recording the old name
#                 is what lets a consumer say "renamed to X" instead of "dead", and repair its own
#                 links. Never remove one: the whole value is that it outlives the move.
#   to:<url>    — a SHELL pointed at a literal URL, for something with no repo to read.
#                Either way the listing says it leaves. Naming someone is not hosting them.
# There is no `type:` flag, on purpose. What a thing IS reads off the category it sits in —
# ANTIBODY at `antibody`, Voices at `voices`, FCPM at `media` — so a second word saying "journal"
# beside the name is noise that can also disagree with the name above it.
#   = <label>  — LAST RESORT ONLY. A name is taken from the thing itself (its <title>); a label
#                here is a second copy of a name that already exists, and it goes stale the day
#                they rename. Use it only where the source is unusable — e.g. a title carrying a
#                tagline. Never for anything of ours.
#
# A listed site that is not answering yet still appears, unlinked — saying "soon" is honest and
# useful; hiding it makes the directory silently incomplete.
#
# `@root` sets which level the APEX lists. anecdote.channel is the name people can remember and
# say out loud, so it shows destinations rather than the top of the tree. Everything currently
# lives under one state; widen this when that stops being true.
@root colorado.anecdote.channel

# `@place` reserves a place before anything is in it. It renders empty, and its TLS coverage is
# checked exactly like an occupied one — a wildcard nobody can see is not a reservation, and the
# cost of standing a place up is paid when it is claimed rather than when someone finally arrives.
@place fort-collins.colorado.anecdote.channel
@place longmont.colorado.anecdote.channel

# itself; nothing here needs changing but the removal of this comment.
@place loveland.colorado.anecdote.channel
@place wellington.colorado.anecdote.channel
